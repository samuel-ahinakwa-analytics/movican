# movican
Movican Micro Credit Enterprise System

## Samvin Analytics — startup waitlist landing page
`/consulting/index.html` is a standalone landing page for Samvin Analytics'
growth/product analytics service for startups, with an email waitlist form.
It does not touch or depend on the Movican app above.

**Before sending real traffic:** open `consulting/index.html` and replace the
`FORM_ENDPOINT` placeholder near the bottom of the file with a real
[Formspree](https://formspree.io) endpoint (or swap in whatever form backend
you prefer). Until that's done, signups only save to the visitor's own
browser and never reach you.
